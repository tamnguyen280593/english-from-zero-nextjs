# Antigravity Agents Configuration

Welcome to the `.agents` directory for the **English From Zero** Next.js project.
This directory houses the Agentic framework setup, demonstrating a sophisticated, senior-level "Vibe Coding" architecture.

By formalizing rules and skills here, the AI agents interacting with this repository follow strict, reproducible constraints regarding content generation, data structure, and UI design without relying on ad-hoc or hallucinated logic.

## Directory Structure
- **`/rules`**: Contains constraints for the agents.
  - `coding-standards.md`: Strict TypeScript and Next.js coding standards (e.g. NO `any` types, Clean Code, proper React hooks usage). Agents must pass their code through this checklist before saving.
  - `content-generation.md`: Ensures the 10-10-15 rule (10 lessons, 10 vocab/phrases, 15 practice items) is strictly adhered to, eliminating data duplication.
  - `ui-design-rules.md`: Ensures responsive, high-contrast UI updates.
- **`/skills`**: Contains actionable, on-demand instructions for agents.
  - `build-json-data/SKILL.md`: Directs the agent on how to correctly compile our raw curated dataset into Next.js readable JSON.
- **`/plans`**: Contains historical and active implementation plans for complex features.

*This structure ensures that any developer or agent joining the project immediately understands the established conventions and workflows.*
